#Quality Model

| Atributo | Definición | Métrica | EC |
| -------- | ---------- | ------- | -- |
| Mantenabilidad | Facilidad para modificar la aplicación | Cobertura de pruebas sobre el 60% | /src/core, /security |
| Seguridad | Protección de datos | Contraseñas cifradas  | /config, /security  |
| Usabilidad   | Facilidad de uso | Transferencias concretadas con el asistente | /src/ui  |
| Fiabilidad | Rendimiento del software | Disponibilidad del servicio sobre el 95% | /src/core |
| Desempeño | Tiempo de respuesta del sistema | Tiempo de inicio y de  procesar transferencias | /src/core, /config  |
| Funcionalidad | Las funciones del sistema cubren las diversas necesidades de la banca | Nivel de aceptación en pruebas de usuario | /docs/SRS |
